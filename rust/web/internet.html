Internet lewat HP 🌐

Buka jendela browser terpisah yang internetnya lewat HP — web app modern, login akun, upload & download jalan normal. Jendela browser lain & aplikasi di laptop tetap memakai koneksi biasanya.

Mengecek proxy…

🪟 Windows Paling mudah

1. Pasang sekali — unduh lalu jalankan. Tombol browser di bawah jadi aktif, dan muncul shortcut di Desktop & Start Menu. Tidak perlu diulang walau IP HP berubah.

⬇ Unduh PocketBridge-Setup.bat

2. Klik browser — terbuka jendela baru (profil khusus) yang internetnya lewat HP. Login di jendela itu tersimpan untuk pemakaian berikutnya.

Chrome Edge Brave Firefox

Browser tidak terbuka? Jalankan setup di langkah 1 dulu. Browser akan bertanya “Buka PocketBridge?” — centang selalu izinkan.
