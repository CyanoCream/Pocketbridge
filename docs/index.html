PocketBridge

HP sebagai jembatan lokal untuk laptop: catatan bersama, internet lewat HP, dan gateway AI.

Catatan bersamaTulis di laptop, langsung muncul di HP, dan sebaliknya.
Internet lewat HPJendela browser terpisah di laptop yang koneksinya lewat HP.
AI gatewayArahkan base URL coding agent ke HP, termasuk respons streaming.

Semua berjalan di jaringan lokal (WiFi/hotspot yang sama). Tanpa akun, iklan, atau pelacakan.
