Syarat & Ketentuan PocketBridge

Berlaku sejak 27 Oktober 2026 · English below

Dengan memasang atau memakai PocketBridge ("aplikasi"), kamu menyetujui syarat berikut. Jika tidak setuju, jangan gunakan aplikasi.

1. Fungsi aplikasi

PocketBridge menjalankan server di HP kamu agar perangkat lain di WiFi/hotspot yang sama dapat memakai catatan bersama, proxy HTTP/HTTPS, dan gateway API AI. Semua server hanya berjalan saat kamu menyalakannya dan berhenti saat kamu mematikannya.

2. Penggunaan yang diizinkan

  • Gunakan aplikasi hanya di jaringan dan perangkat yang kamu miliki atau berhak kamu pakai.
  • Kamu bertanggung jawab mematuhi hukum yang berlaku, aturan kantor/sekolah, kebijakan jaringan, serta ketentuan operator seluler (termasuk aturan tethering dan kuota data).
  • Dilarang memakai aplikasi untuk aktivitas ilegal, mengakses sistem tanpa izin, menyebarkan malware, atau melanggar hak pihak lain.
  • Jika perangkatmu dikelola organisasi (misalnya laptop kantor dengan VPN), pastikan penggunaan aplikasi diizinkan oleh kebijakan organisasi tersebut.

3. Keamanan

  • Lalu lintas di jaringan lokal memakai HTTP dan tidak terenkripsi. Pasang password di aplikasi dan gunakan hanya di jaringan yang kamu percaya.
  • Siapa pun yang tahu password dan berada di jaringan yang sama dapat memakai catatan, proxy, dan gateway.
  • Matikan server saat tidak dipakai.

4. Layanan pihak ketiga

Situs web yang kamu buka lewat proxy dan provider AI yang kamu atur di gateway adalah layanan pihak ketiga. Penggunaannya tunduk pada syarat dan kebijakan privasi masing-masing. API key milikmu tetap tanggung jawabmu, termasuk biaya pemakaian yang timbul.

5. Data

Catatan dan pengaturan disimpan di HP kamu. Pengembang tidak mengumpulkan data. Detailnya ada di Kebijakan Privasi. Kamu bertanggung jawab mencadangkan data penting; data terhapus saat aplikasi di-uninstall.

6. Tanpa jaminan

Aplikasi disediakan "sebagaimana adanya" tanpa jaminan apa pun, tersurat maupun tersirat, termasuk jaminan bahwa aplikasi selalu tersedia, bebas galat, atau cocok untuk keperluan tertentu. Beberapa situs atau layanan mungkin tidak berjalan lewat proxy.

7. Batasan tanggung jawab

Sejauh diizinkan hukum, pengembang tidak bertanggung jawab atas kerugian langsung maupun tidak langsung akibat penggunaan aplikasi, termasuk kehilangan data, biaya kuota atau API, pemblokiran akun, atau pelanggaran kebijakan jaringan pihak lain.

8. Perubahan

Syarat ini dapat diperbarui. Versi terbaru selalu tersedia di halaman ini, dan penggunaan setelah perubahan berarti kamu menyetujui versi terbaru.

9. Kontak

Pertanyaan atau laporan masalah: GitHub Issues.
