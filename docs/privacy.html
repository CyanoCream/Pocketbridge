Kebijakan Privasi PocketBridge

Berlaku sejak 27 Oktober 2026 · English below

PocketBridge ("aplikasi") adalah aplikasi Android yang menjalankan server di jaringan lokal HP pengguna. Kebijakan ini menjelaskan data apa yang ditangani aplikasi dan bagaimana caranya.

Ringkasan

  • Pengembang tidak mengumpulkan, menerima, atau menjual data pribadi apa pun.
  • Tidak ada iklan, analitik, pelacakan, atau SDK pihak ketiga.
  • Semua data disimpan di perangkat pengguna sendiri.

Data yang disimpan di perangkat

  • Catatan yang dibuat lewat halaman web PocketBridge, disimpan di penyimpanan internal aplikasi di HP.
  • Pengaturan: password aplikasi, alamat API provider AI, dan API key opsional, disimpan di penyimpanan internal aplikasi.

Data ini tidak pernah dikirim ke pengembang. Data terhapus saat catatan dihapus atau saat aplikasi di-uninstall.

Lalu lintas jaringan

  • Jaringan lokal: saat server dinyalakan, perangkat lain di WiFi/hotspot yang sama dapat membuka catatan. Lalu lintas lokal ini memakai HTTP dan tidak terenkripsi; gunakan password dan jaringan yang kamu percaya.
  • Proxy & browser ringan: saat pengguna memakai fitur ini, permintaan ke situs web diteruskan melalui koneksi internet HP ke situs yang dituju pengguna. Aplikasi tidak menyimpan riwayat penjelajahan.
  • AI gateway: permintaan diteruskan ke alamat API yang diatur pengguna. Data yang dikirim tunduk pada kebijakan privasi provider tersebut.

Izin aplikasi

  • Internet & status jaringan/WiFi: untuk menjalankan server lokal dan meneruskan permintaan.
  • Layanan latar depan & wake lock: menjaga server tetap aktif saat layar mati, hanya selama pengguna menyalakannya.
  • Notifikasi: menampilkan status server dan tombol untuk mematikannya.

Anak-anak

Aplikasi ini tidak ditujukan untuk anak di bawah 13 tahun dan tidak dengan sengaja mengumpulkan data dari mereka.

Perubahan

Kebijakan ini dapat diperbarui. Perubahan akan dipublikasikan di halaman ini. Lihat juga Syarat & Ketentuan.

PocketBridge Privacy Policy

Effective October 27, 2026

PocketBridge ("the app") is an Android app that runs a server on the user's local network. This policy explains what data the app handles and how.

Summary

  • The developer does not collect, receive or sell any personal data.
  • No ads, analytics, tracking or third-party SDKs.
  • All data stays on the user's own device.

Data stored on the device

  • Notes created through the PocketBridge web page, stored in the app's internal storage on the phone.
  • Settings: app password, AI provider API address and optional API key, stored in the app's internal storage.

This data is never sent to the developer. It is removed when notes are deleted or the app is uninstalled.

Network traffic

  • Local network: while the server is on, other devices on the same Wi-Fi/hotspot can open the notes. This local traffic uses HTTP and is not encrypted; use a password and a network you trust.
  • Proxy & lightweight browser: when used, web requests are forwarded through the phone's internet connection to the sites the user chooses. The app does not store browsing history.
  • AI gateway: requests are forwarded to the API address configured by the user and are subject to that provider's privacy policy.

Permissions

  • Internet & network/Wi-Fi state: to run the local server and forward requests.
  • Foreground service & wake lock: to keep the server running with the screen off, only while the user has it switched on.
  • Notifications: to show server status and a button to stop it.

Children

The app is not directed at children under 13 and does not knowingly collect data from them.

Changes

This policy may be updated. Changes will be published on this page. See also the Terms & Conditions.
